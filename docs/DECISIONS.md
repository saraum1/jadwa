# DECISIONS — قرارات يجب الحفاظ عليها

1. الاسم جدوى. المستخدم مصممة والهوية supplied؛ لا يُعاد رسم الشعار أو تمديده أفقيًا. الأيقونات خطية بسيطة دون مربعات مستقلة حولها حيث اعتمد ذلك.
2. واجهة عربية RTL، خط IBM Plex Sans Arabic، أبيض/رمادي فاتح وكحلي وأزرق ونعناعي. العملة رمز الريال الجديد من SVG محلي، لا ر.س.
3. المنتج يجيب: كم الوفر/التسرب؟ لماذا؟ وما الخطوة؟ الواجهة لا تتحول لبرنامج محاسبة كثيف.
4. تم اعتماد مشروع مستقل static أولًا. لا framework أو dependencies في runtime حاليًا.
5. المنتجات والمخزون في صفحة واحدة بتبويبين. المصروفات ومركز البيانات صفحتان منفصلتان.
6. ملف مرفوع = تجهيز محلي فقط في هذه النسخة، لا ادعاء تحليل ذكي أو تحديث الأرقام تلقائيًا.
7. الغرفة كانت منفصلة ثم دُمجت عبر زر اجتماع، مع نافذة اختيار الملفات قبل الانتقال. لا تُحمّل WebGL كاملًا في اللاندنق؛ تستخدم صورة معاينة ثم انتقال.
8. منظور الغرفة من مكان المستخدم مقابل الروبوت، مع كرسي مقابل. حركة نظر صغيرة يمينًا ويسارًا وأعلى وأسفل، وليست لعبة مشي حر.
9. تحسينات معتمدة شملت النبات، اللابتوب، كرات نيوتن بدل التركيز على لوحة شعار صغيرة على الطاولة، الكوب والطاولة، المفاصل والأيدي، اللوح الأزرق إلى الأرض والسقف، الرف والفازات، المنظر الخارجي والسجادة والجدران وتوسيط الوجه.
10. الروبوت وجه ودود وشاشة كحلية وعيون نعناعية وجسم فاتح ولمسات زرقاء، مستند إلى الصورة الأمامية المعتمدة. النسخة الإجرائية ليست تطابقًا فوتوغرافيًا كاملًا مع صورة التوليد.
11. الأنميشن المحلي أولًا ثم API لاحقًا. لا تظهر حالات استماع أو نطق توهم بوجود اتصال حقيقي الآن.
12. اللاندنق مستوحاة من إيقاع العروض في Awwwards، دون نسخ مواقع. Clear Street مرجع دخول، وInfinityFX مرجع typography. لا شهادات عملاء أو أسعار أو نتائج مختلقة.
13. مقدمة الشعار نحو 1.9 ثانية، مرة في جلسة التبويب، مع تجاوز وتقليل الحركة وفشل آمن. لا حركة تعطل الزائر أكثر من المهلة الاحتياطية.
14. حركات السكرول مستقلة للعناصر، تدرج 90ms بحد 270ms، دخول من أسفل وتكبير خفيف لصورة الغرفة.
15. index.html هي اللاندنق منذ الإصدار 23، وdashboard.html لوحة التحكم. جميع عودات الصفحات والغرفة تعود إلى dashboard.html.
16. في آخر طلب حسابات، اختارت المستخدم صراحة «واجهات للديمو الآن». إبقاء توضيح عدم تفعيل الحسابات ضروري إلى أن يتغير النطاق.
17. مشاركة الموقع عامة كما كانت؛ لا تغيّر جمهور النشر تلقائيًا. النسخة المضغوطة تسليم فقط ولم تستدع إعادة نشر الموقع.
18. قبل عمل جديد اقرأ التوثيق والكود، بيّن الفهم والخطة والملفات المتوقع تغييرها، واستند إلى موافقة المستخدم. لا تعدل غير المرتبط ولا تُدخل نمطًا معماريًا لمجرد أنه شائع.

## React migration — 2026-10-04

اعتمد طلب المستخدم نقلًا كاملًا إلى React وتنظيمًا حسب الميزات. اختير Vite multi-page للحفاظ على .html وعزل CSS ودورة حياة البيانات. لم نضف router أو framework للحركة. حُفظ المحرك WebGL الحالي مع adapter قابل للتنظيف. CSS والأصول ومفاتيح sessionStorage بقيت متوافقة. الأصل داخل project لم يتغير؛ وصف المعمارية السابق محفوظ في history/v25-docs.

## جدوى AI — 2026-10-05

الكود يحسب والذكاء الاصطناعي يشرح؛ لا أرقام من النموذج. نفس العقل للشات والاجتماع. Gemini على الخادم (Netlify Functions) والمفتاح لا يدخل الواجهة. اختارت المستخدم تطبيق العقل في الشات والاجتماع فقط دون تغيير أرقام الصفحات. القرار 11 (لا حالات استماع/نطق وهمية) ما زال ساريًا: الحالات تظهر فقط مع اتصال حقيقي.
