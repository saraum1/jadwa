# Parity checklist

- [x] development يعمل، production build ناجح، المداخل التسعة موجودة.
- [x] 13 اختبارًا: حسابات الفترتين، مصالحة التكاليف، قوالب CSV الأربعة، escaping والأسطر، رفض الشهور المختلطة والقيم غير الصالحة، البحث، الساعة والحركة وتنظيف المحرك وإعادة تركيبه.
- [x] الرئيسية: تغيير سبتمبر إلى أغسطس، القوائم، نافذة خيارات الاجتماع.
- [x] المنتجات/المخزون: رابط مباشر للصنف، التفاصيل، البحث، إغلاق النافذة.
- [x] المصروفات: تصفية opportunity=2، نافذة مطابقة36000 =25200+1600+9200.
- [x] الفرص: جديدة → تنفيذ → انتظار القياس → مكتملة، إدخال1600/1200 يعرض400 تجريبيًا مع التحذير السببي.
- [x] مركز البيانات: رفع CSV محلي، اقتراح الأعمدة، dropdown داخل dialog، فحص، تأكيد، تحديث الصفحة، تفاصيل الملف.
- [x] بيانات جاهزة → اجتماع بأربعة ملفات؛ سياق الشهر محفوظ.
- [x] التسجيل: أخطاء الحقول المطلوبة، إدخال تجريبي صحيح، رسالة عدم تفعيل الحسابات دون إرسال أو حفظ كلمات المرور.
- [x] اللاندنق: المقدمة تنتهي، تبويب المصروفات يبدّل الجدول والمحتوى والرابط.
- [x] مقارنة التخطيط للصفحات التسع على375×812 و430×932 و1366×768 و1920×1080. أدلة JSON وصور جانبية داخل qa/. المقاسات الكبيرة مصغرة للعرض الجانبي، وviewport الداخلي بالقياس المطلوب.
- [x] لا تمرير أفقي في قياسات body، وتطابقت ارتفاعات الصفحات بعد استقرار الخطوط. الأبعاد لا تعني تطابق كل بكسل أو كل حالة.
- [x] الأصول والشعار ورمز الريال وCSS الأصلي محفوظة؛ React فعلي بلا iframe/حقنHTML في runtime. استُخدمت iframes فقط في أداة مقارنة مؤقتة أزيلت من التطبيق.
- [x] لم تظهر أخطاء console خاصة بالتطبيق في الجولة المفحوصة؛ ظهرت رسائل تخص إضافة المتصفح واستُبعدت من نتيجة التطبيق.
- [x] fallback للغرفة جُرّب فعليًا.
- [ ] حركة الغرفة وإضاءة GPU وcontext restoration بصريًا: لم تتوفر WebGL في المتصفح. المصادر محفوظة واختبار lifecycle ناجح.
- [ ] اختبارات كل حالات drag/touch/keyboard/reduced motion والمتصفحات الأخرى: لم يُنفّذ تدقيق شامل لها؛ المنطق منقول ومراجع.

الأصل عُرض عبر نسخة مؤقتة في نفس خادم المقارنة لأن بيئة المعاينة تسمح بمنفذ واحد. المصدر الأصلي لم يُعدّل. لقطات المقارنة ليست مقارنة إطارات متزامنة لحركة الروبوت.
