# جدوى — React migration

نسخة React + Vite منظمة حسب الميزات، مبنية على الإصدار 25. الأصل محفوظ دون تعديل في `project/`، وسياقه وتاريخه ومصادر الغرفة والصور كلها مرفقة.

## التشغيل

يلزم Node.js 22.12+ أو إصدار 24. من هذا المجلد:

```sh
npm ci
npm run dev
```

افتح http://localhost:4173 . للبناء: `npm run build`، ولمعاينة الإنتاج: `npm run preview`، وللاختبارات: `npm test`.

`react-app/dist/` يتضمن بناء الإنتاج الجاهز؛ يُنشر على استضافة static. لا تفتح HTML عبر file://. يجب تقديم المشروع من جذر الاستضافة كما في الأصل.

## محتويات الحزمة

- `react-app/`: الكود الحالي، المكونات والميزات، الأصول، الاختبارات، lockfile وبناء الإنتاج.
- `project/`: المصدر الأصلي المطابق للإصدار 25، بما فيه هندسة الغرفة وPython والرندرات والمخططات.
- `docs/`: التوثيق الحالي وخريطة التحويل والقيود وتقرير المقارنة.
- `history/`: تاريخ Git الأصلي ووثائق الإصدار السابق دون محوها.
- `references/`: الهوية والمراجع والصور الأصلية.
- `tools/` و`exports/`: أدوات وتصديرات الإصدار الأصلي؛ ليست تشغيلًا لنسخة React.

التطبيق React متعدد المداخل للحفاظ على مسارات `.html` وعزل CSS وسلوك الانتقال الأصلي. كل الواجهات JSX وحالات React، والغرفة وحدها تستخدم canvas/WebGL عبر adapter. لا يوجد iframe أو HTML قديم محقون في تشغيل التطبيق.

**جدوى AI مفعّل:** «اسأل جدوى» والاجتماع الصوتي مربوطان بـ Gemini عبر دوال Netlify، والأرقام من محرك حساب داخلي. التفاصيل والنشر في `docs/AI.md`. نجح البناء و13 اختبارًا. فُحصت الصفحات بمقاسات الجوال والمكتب. متصفح الفحص لم يوفّر WebGL؛ تم اختبار fallback ودورة حياة المحرك، ولم يُدّع اختبار الحركة ثلاثية الأبعاد بصريًا. التفاصيل في `docs/KNOWN_LIMITATIONS.md` و`docs/PARITY_CHECKLIST.md`.

النسخة الأصلية المنشورة لم تُستبدل أثناء هذا الترحيل.
